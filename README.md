# 3git Self Hosted Git Platform Graphic

Designed a new graphic for the portfolio called 3git, a self-hosted Git platform concept.

The logo blends circuit board traces and Git branching pathways into a bold orange numeral 3, set against a dark textured background with crisp typography. Focused on creating a clean visual identity for local-first, self-hosted developer infrastructure.
